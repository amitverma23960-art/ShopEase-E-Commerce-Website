ShopEase – E-Commerce Website

Project Overview

ShopEase is a full-stack e-commerce web application developed to provide a simple and user-friendly online shopping experience.

The application allows users to browse products, search and filter products, add items to their cart, and place orders. It also provides an admin section for managing products and orders.

Features

- Responsive user interface
- Product listing and product catalog
- Product search functionality
- Category-based filtering
- Price sorting
- Shopping cart management
- Add and remove products from cart
- Customer checkout
- Order placement with unique Order ID
- Admin product management
- Add, edit, and delete products
- Order management
- Order status updates
- Dashboard with product, order, revenue, and pending order statistics
- MongoDB database integration

Installation and Setup

1. Clone or download the project.
2. Open the project folder in Visual Studio Code.
3. Install the required dependencies:

npm install

4. Make sure MongoDB is installed and running.
5. Start the application:

node server.js

6. Open the local application URL in your browser.
